# Black Arrow

To-the-point notes and reference on ML performance engineering.

Read it at <https://deependujha.github.io/black-arrow/>.

## Writing

```sh
cargo install mdbook --version 0.5.4   # or: brew install mdbook
mdbook serve --open                    # live preview at localhost:3000
```

Add a page by listing it in `src/SUMMARY.md`; `mdbook serve` creates the missing file.

Pushing to `main` builds the book and deploys it to GitHub Pages.
